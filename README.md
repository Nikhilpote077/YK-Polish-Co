# YK Polish Co. — Professional Static Website Starter

## What is included

- Shared header, footer and mobile navigation via `assets/js/components.js`
- Central business configuration in `assets/js/config.js`
- Product data in `assets/js/products.js`
- Catalogue filtering in `assets/js/filters.js`
- Responsive design using the existing custom design system + Bootstrap utilities
- Shop, collections, custom order, sizing, journal, contact and policy pages

## Important before launch

1. Replace placeholder WhatsApp, phone, email and Instagram values in `assets/js/config.js`.
2. Replace sample product data and starter sizing values with the real catalogue.
3. Add real product photography under `assets/images/products/`.
4. Review all policy pages with the business owner.
5. Connect a real order/payment/backend flow before taking online payments.
